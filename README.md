# My Pygame 2D Shooter

Hey! Welcome to my 2D shooter platformer game. I built this game in Python using the `pygame` library, with awesome sound effects and collisions with enemies and the environment. This game is a practice project for my Python knowledge and a way to improve my coding experience.

The game has only 3 levels. I could make more, but it is just a demo for now. Each level gives the player a different environment to explore while dealing with enemies and obstacles. The main goal is to move through the levels, avoid enemies, shoot them, and use grenades when needed.

During development, I tried to make the gameplay enjoyable while also learning how to organize the different parts of a game. I worked on connecting the player with the enemies and the environment, making sure the collisions work properly and adding sound effects to make the experience better.

I also learned that even a small game needs a lot of logic behind it, and fixing bugs sometimes takes more time than writing the actual code. Working on the different mechanics helped me understand how the player, enemies, and environment need to interact with each other.

## How To Run

Just download the `.exe` from the Releases section and run `main.exe`. You don't need to run the Python source code if you choose this option.

## Controls

* **Move:** Left / Right Arrows (or A/D)
* **Jump:** W
* **Shoot:** Spacebar
* **Grenade:** Q

## Why I Built It

I built this game as one of my first detailed 2D games using classes and OOP. It helped me understand how to organize a bigger project instead of putting everything into one file. This experience also helped me when building my other Pygame games because I became more comfortable working with multiple classes and connecting different parts of the game.

## What I Used to Build It

I used the Pygame library, a Python module for making games, and I think it worked really well for this project. I also used a tile maker to create the levels and organize the tiles in the game.

Making this project gave me more confidence in Python and motivated me to keep experimenting with game development. There are still many things I could add or improve, but for now, I am happy with how this demo turned out.
